# Changelog

## 1.0.1 — 2026-10-26 — Android preview

- New VITALIS symbol and adaptive launcher icon.
- Conversation-first design, Chats home and Saved navigation.
- Browse/Installed/Downloads model sections with a separate filter sheet.
- Separate app and chat settings; native-compatible numeric generation controls.
- Retained unsaved drafts, chat-owned asynchronous prompt results and guarded editor admission.
- Profile-mode Android APK; formal qualification and coverage remain incomplete.
- Windows preview is the next delivery target; Linux remains deferred.

## 1.0.0 — Android development preview

- Persistent runtime ownership, acknowledged cancellation and recovery handling.
- Local GGUF registry and public Hugging Face model search/download flows.
- Personas, persistent note attachments, per-chat settings and saved conversations.
- Complete stored-history clipboard export, including messages outside the loaded page.
- Individual note attachment controls and theme-aware note contrast.
- Privacy wording that distinguishes local inference from model-library networking.
- Download reinstallation no longer deduplicates against completed historical jobs.
- Search focus is dismissed on tab changes/submission; accepted downloads show their progress screen.
- Acknowledged paused progress includes retained bytes that arrived after the last poll.
- Apache-2.0 licensing for original VITALIS application work, preserving third-party licences.

Known gaps and incomplete qualification are listed in [validation status](docs/public/STATUS.md). This entry is not a production release declaration.
