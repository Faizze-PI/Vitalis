# Security

This is a development preview; it does not have a production security certification or a supported-release security SLA.

Never include credentials, private chats, model filesystem paths, database copies, keystores or full device dumps in public issues or pull requests.

For a sensitive issue, request a private reporting channel from the repository owner before sharing technical details. If GitHub private vulnerability reporting is available for this repository, use it. Do not assume an unverified email address is a secure disclosure route.

No production signing credentials are included. Do not introduce signing keys, cloud-inference fallback, unrestricted download redirects, destructive automatic database recovery or raw prompt logging.
